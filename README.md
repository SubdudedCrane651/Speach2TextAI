A Python program to convert .wav Speech 2 text using OPENROUTER Whisper AI model.

Also added a Text to speech convertor useing a free AI model called deepgram/flux-tts:free. Only for english text unfourtunately other languages for the AI models like Google cost alot. Try them if you like if you want to spend alot of money.

First need an api key for the model Whisper AI at OPENROUTER.

Place it in a config.json file like this

{
    "OPENROUTER_API_KEY": "YOURAPI-KEY"
}
